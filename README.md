# YourDiary

YourDiary 是一款 Android 本地离线日记应用。

取法 李慈铭《越缦堂日记》的记事方式：一日可有多则，一事一条。
> 细大必书，积玉碎金，一日不定几例，一事一条，所读何书，所见何人，所遇何事，皆日常直录。
> 以记事为要，议论次之。
> 记载从清咸丰到光绪四十年之间的大量治学札记、朝野见闻、朋踪聚散、人物评述、古物考据、书画鉴赏、山川游历及各地风俗。

它的首要场景是事情发生当下的快速记录。

## 产品边界

- 自动记录且不可修改条目的创建时间；正文使用 Markdown，无标题字段。
- 一条记录可附多张相册照片和多个 Tag；正文、照片和 Tag 自动保存并可编辑。
- 首页显示今天的倒序时间线；历史页以左侧时间线连续向前浏览，提供全文搜索与 Tag 筛选。
- 删除直接进入保留 30 天的回收站。
- 数据仅保存在本机：PIN 必设，生物识别可选；应用后台或屏幕熄灭后立即锁定。
- 数据库、照片、缩略图、搜索索引与手动导出的备份均需要加密。备份只包含活动日记，不包含回收站；恢复可合并并按稳定标识去重。

首版不包含账号、同步、网络服务、内置拍照、第三方格式导入、自动备份、日历主入口和富文本编辑器。

完整的产品规则、错误处理与验收标准见 [specs.md](specs.md)。项目协作与实现约束见 [AGENTS.md](AGENTS.md)。

## 当前工程状态

当前仓库是 Kotlin Android 工程模板，尚未实现上述产品功能。现有工程采用 XML、ViewBinding 与 Fragment Navigation，并已使用 Material 3 主题；这不表示完整的日记界面已实现。具体的 Material 3 页面实现、分层迁移、加密存储和备份方案将在实现计划中确定。

## 设计与工程原则

- 界面遵循 Google Material 3，以低干扰、留白和清晰时间线营造纸质日记感。
- 代码按功能域划分 `ui`、`domain`、`data`，并保持 `ui → domain ← data` 的依赖方向。
- 所有安全、恢复与数据一致性规则以 `specs.md` 为准，并需要自动化和设备级验证。
- Android 系统自动备份和设备到设备迁移不得携带日记私有数据；备份只由用户手动导出。
